# Core

Elementos verdaderamente compartidos: clases base, utilidades pequeñas, validaciones generales y excepciones comunes. No debe convertirse en un depósito de lógica sin dueño.

También contiene la vista institucional pública `landing` y su ruta de inicio.
No consulta datos clínicos. El diseño y la guía de mantenimiento se describen
en `docs/landing-page.md`.
